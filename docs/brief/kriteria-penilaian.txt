Kriteria Penilaian
Bootcamp Perempuan Inovasi 2026
Final Project - AI Full Stack Web Development
Penilaian
Penilaian dilakukan berdasarkan aspek berikut.
Umum
* Correctness, design, dan style.
* Aplikasi memiliki minimal 1 fitur end-to-end dan berfungsi sesuai dengan rancangan.
* BRD dan Prototype.
* Kemampuan peserta menggunakan Git dan GitHub.
* Deck presentasi.
* Video presentasi.
Front-End
* UI dan UX design, serta penggunaan Tailwind CSS dan shadcn/ui.
* Website sudah responsive.
* Implementasi component, error handling, dan validasi input.
* Penggunaan state, props, dan React Context.
* Routing pada App Router dan struktur project Next.js.
* Jumlah halaman website sesuai ketentuan.
* Konten sesuai dengan tema website, tanpa konten dummy seperti Lorem Ipsum.
* Antarmuka fitur AI yang jelas, dengan penanganan loading, hasil kosong, dan error.
Back-End
* Jumlah endpoint API sesuai spesifikasi.
* Validasi dan error handling API.
* Deployment dan konfigurasi production.
* Arsitektur dan kualitas kode Back-End (Route Handlers dan Server Actions).
* API Documentation.
Database
* ERD atau Schema Diagram, termasuk data untuk fitur AI.
* Implementasi database di Supabase (schema, relasi, seed).
* Keamanan database dengan Row Level Security (RLS).
AI Integration
* Kesesuaian fitur AI dengan kebutuhan produk dan problem statement.
* Pemahaman terhadap use case AI yang dipilih dan model yang digunakan.
* Pemenuhan ketentuan teknis sesuai use case (Recommendation System, RAG, atau Computer Vision).
* Integrasi fitur AI ke dalam aplikasi Full-Stack secara end-to-end, dan berfungsi di environment production.
* Keamanan integrasi AI, termasuk perlindungan kunci akses dan pembatasan input.
* Penanganan kondisi loading, hasil kosong, dan error pada fitur AI.
* Evaluasi sederhana terhadap hasil AI.
* Penggunaan AI yang bertanggung jawab: batasan, bias, dan privasi data.
* Dokumentasi model, data, input, dan output.
