8 Oktober 2026

1. TEKNOLOGI YANG DIGUNAKAN
----------------------------------------

- Next.js 16.3.8
- React 19.2.8
- App Router
- JavaScript dan JSX
- Tailwind CSS v4
- lucide-react untuk ikon


2. SETUP DAN KONFIGURASI
----------------------------------------

Pekerjaan yang telah diselesaikan:

- Memastikan proyek menggunakan Next.js dengan App Router.
- Memastikan Tailwind CSS telah terpasang dan terhubung melalui PostCSS.
- Menambahkan dependency lucide-react.
- Menyinkronkan package-lock.json melalui npm install.
- Mengatur metadata aplikasi Ayomi.
- Mengubah bahasa dokumen HTML menjadi Bahasa Indonesia.
- Menambahkan branding dan token warna dasar Ayomi.
- Menambahkan pengaturan font dasar pada global stylesheet.
- Menambahkan aturan font inheritance untuk elemen form.

File konfigurasi terkait:

- app/layout.js
- app/globals.css
- package.json
- package-lock.json
- postcss.config.mjs
- next.config.mjs

4. KOMPONEN UI REUSABLE
----------------------------------------

Komponen reusable berikut telah dibuat pada folder components/ui/:

1. Button.js
   - Variant primary, secondary, dan ghost.
   - Ukuran sm, md, dan lg.
   - Dukungan ikon kiri atau kanan.
   - Disabled state.
   - Opsi full width.

2. Badge.js
   - Variant green, white, yellow, dan grey.

3. Card.js
   - Variant warna white, yellow, green, dan blue.
   - Dukungan className tambahan.

4. ToggleSwitch.js
   - Controlled checked state.
   - Callback onChange.
   - Disabled state.
   - Dukungan role switch dan aria-checked.

5. Modal.js
   - Ukuran sm, md, dan lg.
   - Overlay dan tombol close.
   - Menutup modal dengan tombol Escape.
   - Dukungan role dialog dan aria-modal.

6. Input.js
   - Text, number, password, dan textarea.
   - Ikon kiri atau kanan.
   - Placeholder.
   - Disabled state.
   - Pesan error dan aria-invalid.

7. ProgressBarWithCard.js
   - Nilai progress 0 sampai 100.
   - Label dan subtitle.
   - Warna progress custom.
   - Dukungan role progressbar.

8. ProfilePicture.js
   - Menampilkan gambar profil.
   - Fallback berupa inisial nama.
   - Ukuran sm, md, dan lg.
   - Opsi warna acak berdasarkan nama.

9. Dropdown.js
   - Daftar pilihan.
   - Controlled value.
   - Placeholder.
   - Ikon opsional.

10. StarRating.js
    - Rating 1 sampai 5 bintang.
    - Mode interaktif.
    - Mode readonly.
    - Ukuran sm dan md.

11. Tabs.js
    - Tab aktif.
    - Callback pergantian tab.
    - Dukungan overflow horizontal.
    - Atribut aksesibilitas tab.

12. Banner.js
    - Tipe info, warning, dan ai.
    - Judul dan deskripsi.
    - CTA opsional.

13. Toast.js
    - Tipe success dan error.
    - Tombol close.
    - Dukungan role alert.

14. utils.js
    - Utility cn untuk menggabungkan class Tailwind secara kondisional.
